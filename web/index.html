어떤 도구가 불러들인 내용이 이후 턴들에서 많이 다시 읽혔는지 보여줍니다.

턴 진행에 따른 대화 문맥 크기 변화

턴이 진행되면서 매번 모델에 다시 전달되는 전체 문맥(컨텍스트)의 크기입니다.

기법별 유효 실행 평균

측정값이 유효한 실행만 모아 계산한 조건별 평균입니다.

유효 실행 수는 실행 오류 등으로 평균에서 제외된 실행을 빼고 센 숫자입니다. 평균 열은 모든 회차를 합친 단순 평균이고, BASE 대비 열은 그 시점까지의 최근 BASE와 먼저 비교한 뒤 평균한 값입니다. 총 사용 토큰(처리 토큰)은 캐시에서 다시 읽은 양까지 합친 주 모델 기준 수치입니다.

회차별 평균 비용

날짜별 기법 평균 비용입니다. 범례에 마우스를 올리면 해당 기법을 강조합니다.
