BASE 대비 조건별 평균

각 회차 안에서 그 회차의 BASE 평균과 견준 뒤, 회차별 차이를 다시 평균했습니다. 왼쪽이 절감, 오른쪽이 증가입니다.

조건별 요약

noise floor는 같은 회차에서 조건이 똑같은 BASE 실행끼리 벌어진 폭입니다. 차이가 이 폭 안에 있으면 조건의 효과로 읽을 수 없습니다.

평균 열은 모든 회차를 합친 값이고, vs BASE 열은 각 회차 안에서 그 회차의 BASE와 비교한 뒤 평균한 값입니다. 회차마다 BASE가 다르므로 두 열을 직접 나눠 보면 맞지 않습니다.

여기의 처리 토큰은 주 모델(Sonnet 5)의 턴 합계입니다. Claude Code가 부수적으로 쓰는 보조 모델(Haiku 4.5, 실행당 약 0.1%)은 턴으로 분해되지 않아 빠져 있습니다. docs/GENERATED_RESULTS.md의 표는 두 모델을 합산하므로 소수점에서 갈립니다.

핵심 지표: context tax

tool result가 컨텍스트를 키우면 그 비용은 한 번으로 끝나지 않습니다. 남은 턴이 모두 그 내용을 다시 읽기 때문에 턴 수만큼 거듭 청구됩니다. 합계만 보여 주는 결과표에는 이 숫자가 드러나지 않습니다.

턴 컨텍스트 = input + cache_creation + cache_read (provider 보고값) · result = 컨텍스트 증가분 − 직전 턴 output · tax = result × 이후 남은 턴 수
