토큰 절약 실험 관측소

Claude Code의 토큰 절약법이 어느 활동에서 토큰을 아끼는지 턴 단위로 측정합니다.

개요

지금까지 쌓인 회차 전체를 합쳐, 어떤 절약법이 실제로 토큰을 줄였는지 봅니다.

지금까지의 결과

모든 회차를 합쳐 내린 현재까지의 판단입니다.

—

누적 현황

이 페이지가 근거로 삼는 데이터의 규모입니다.

BASE 대비 조건별 평균

각 회차 안에서 그 회차의 BASE 평균과 견준 뒤, 회차별 차이를 다시 평균했습니다. 왼쪽이 절감, 오른쪽이 증가입니다.

해석 가이드

위 막대를 어떤 기준으로 읽어야 하는지입니다.

조건별 요약

조건마다 BASE와의 평균 차이, 그리고 그 차이를 효과로 읽어도 되는지입니다.

noise floor는 같은 회차에서 조건이 똑같은 BASE 실행끼리 벌어진 폭입니다. 차이가 이 폭 안에 있으면 조건의 효과로 읽을 수 없습니다.

실행 상세

선택한 실행 하나를 턴 단위로 분석합니다.

실행 요약

이 실행이 무엇을 얼마에 했는지, 그리고 측정값을 신뢰할 수 있는지입니다.

토큰이 가장 많이 든 턴

한 번의 도구 결과가 이후 턴에 누적되어 전체 비용에서 차지한 몫입니다.

턴별 context tax

막대 하나가 한 턴의 tool 호출이 이후 턴들에 걸쳐 청구시킨 총량입니다.

툴별 누적 context tax

같은 양을 어떤 도구가 불러들였는지로 나눠 본 것입니다.

컨텍스트 성장

턴이 진행되며 매 턴 모델에 다시 실리는 컨텍스트의 크기입니다.

BASE 대비

같은 회차의 BASE 평균과 견준 것입니다. 다시 청구된 컨텍스트의 차이를 네 항목으로 나눕니다.

네 항목의 합은 실측 차이와 정확히 같습니다.

턴 데이터

차트의 모든 수치는 이 표에서, 이 표는 data/activity-log.csv에서 옵니다.

결과 검증

실험 결과가 반복 가능하고 신뢰할 수 있는지 검증합니다.

조건별 요약

측정 유효한 실행만 평균에 넣은 조건별 전체 수치입니다.

평균 열은 모든 회차를 합친 값이고, vs BASE 열은 각 회차 안에서 비교한 뒤 평균한 값이라 두 열을 직접 나눠 보면 맞지 않습니다. 처리 토큰은 주 모델(Sonnet 5)의 턴 합계이며, 보조 모델(Haiku 4.5, 실행당 약 0.1%)은 턴으로 분해되지 않아 빠져 있습니다.

회차별 추세

회차가 쌓이면 조건별 선이 길어집니다. 코드 수정은 필요 없습니다.
