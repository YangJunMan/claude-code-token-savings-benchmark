토큰 절약 실험 관측소

Claude Code의 토큰 절약법이 어느 활동에서 토큰을 아끼는지 턴 단위로 측정합니다.

context tax

tool result가 컨텍스트를 키우면 그 비용은 한 번이 아닙니다. 남은 모든 턴이 그것을 다시 읽으므로 턴 수만큼 반복 청구됩니다. 합계만 보는 결과표에는 이 숫자가 보이지 않습니다.

턴 컨텍스트 = input + cache_creation + cache_read (provider 보고값) · result = 컨텍스트 증가분 − 직전 턴 output · tax = result × 이후 남은 턴 수

이 실행에서 가장 비싼 활동
